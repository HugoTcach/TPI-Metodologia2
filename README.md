# Sistema de Gestión de Solicitudes Académicas (TPI)

## Descripción
Este repositorio contiene el Trabajo Práctico Integrador (TPI) para la asignatura Metodología de Sistemas II. El proyecto demuestra la evolución de un módulo de software desde una arquitectura inicial monolítica con alta deuda técnica hacia un diseño profesional aplicando principios SOLID, Clean Code y refactorizaciones seguras.

## Funcionalidades
- Registrar nueva solicitud.
- Cambiar estado de solicitud.
- Asignar responsable.
- Generar reporte simple.

## Tecnologías Utilizadas
- Lenguaje: Python 3.12
- Persistencia: Archivo local (JSON)
- Control de Versiones: Git / GitHub

## Instalación y Uso
1. Clonar el repositorio.
2. Asegurarse de tener Python 3 instalado.
3. Ejecutar el sistema mediante la consola: `python main.py`.
